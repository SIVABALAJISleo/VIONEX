# Security Policy

## Reporting a Vulnerability

The VIONEX team takes application, API, media pipeline, and user account security seriously.

If you believe you have discovered a security vulnerability in VIONEX, please do NOT disclose it publicly.

Instead, please send an encrypted report to:
- **Email:** security@vionex.tv
- **Response SLA:** Within 48 hours for triage confirmation.
- **Fix Timeline:** Critical severity patches are released within 7 days.
